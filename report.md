# Superstore Sales Dashboard Report

## objective
The objective of this project is to analyze sales and profit performance using an interactive streamlit dashboard.

## Tools Used
 Python
 Pandas
 Streamlit
 plotly
 VS Code
 GitHub

 ## Dataset Information
 The dataset contains sales transaction including category, region, customer segment, sales, quantity, and profit.

 ## features Implemented
  KPI Metrics
  Sales Analysis
  Profit Analysis
  Forecast Analysis
  Customer Segmentation
  Interactive Filters
  Charts and Visualization

  ## Business Insights
  Technology generated the highest profit
  West Region had strong sales performance
  Some products had high sales but low profit

  ## Challenges Faced
  Some streamlit deployment and sidebar issues were resolved during development.

  ## Conclusion
  The dashboard helps businesses monitor performance and make better decisions using data insights.
